## Гипотеза

На научных фразах выбор среди K гипотез Whisper по сумме оценки распознавателя и оценки грамматики повышает точное совпадение AST относительно top-1 Whisper и текущего `interpret_utterance`. Ожидание плана: ошибка распознавания термина часто даёт неразбираемый или маловероятный по грамматике вариант, а верный AST есть среди K.

Это гипотеза. Файл её не подтверждает.

## Откуда берутся примеры

Только корпус voice-v1, после того как он запечатан хешем манифеста.

| Роль | Дикторы | Split в voice-v1 | Что можно делать |
|---|---|---|---|
| Подбор λ | `spk01`, `spk02`, `spk03` | train | выбрать λ |
| Test | `spk04`, `spk05` | `dev_holdout` | один подсчёт |

`dev-seed-v3`, `ambiguous-v2`, `nomenclature-v1` и `prose-negatives-v2` этим вопросом не отвечают: это текст автора, и `dev_holdout` внутри них уже открывался. Прозаические записи voice-v1 входят в знаменатель false scientific rewrite rate.

Один диктор целиком в одном split. Интервал по записям, а не по дикторам, для этого вопроса не публикуется.

## Гипотезы распознавателя

K берётся из множества {1, 2, 4, 8}.

Версия question-1-v1 получает список повторными прогонами локального Whisper с температурой больше нуля и фиксированными seed (вариант (a) плана). Варианты (b) и (c) плана — другой протокол.

В коде сейчас температура по умолчанию равна 0 (`crates/sciwhisper-asr/src/engine.rs`). Ноль не даёт списка из нескольких гипотез. Числа для прогона записываются в раздел «Запечатано» ниже до первого подсчёта test: одна температура из интервала (0, 1], восемь seed для K = 8, меньшие K — префиксы того же списка. Пока раздел пуст, подсчёт test этим файлом запрещён.

Оценка ASR гипотезы — сумма логарифмов вероятностей токенов. Если распознаватель такой суммы не отдаёт, прогон останавливается и публикуется этот факт, а не замена на другую величину.

## Скор

Для каждой гипотезы:

`скор = λ · ASR + (1 − λ) · грамматика`

Грамматика — `log P` дерева по PCFG, когда такая величина есть в репозитории отдельной функцией. PCFG в дереве сейчас нет (пункт плана открыт). До этой функции подсчёт test запрещён. Подставленная вручную оценка, которой нет в коде на момент запечатывания, результатом вопроса 1 не является.

λ выбирается только по дикторам train, по сетке из раздела «Запечатано». На test λ не пересматривается. При равенстве скоров побеждает гипотеза, которая раньше в списке распознавателя.

## Базы

Обе базы считаются на тех же записях.

1. Top-1 Whisper при тех же параметрах распознавания, затем текущий `interpret_utterance`.
2. Первая гипотеза из списка, которую разборщик принимает, без PCFG.

## Метрики

Главная — AST exact match, парно: точный тест Макнемара и бутстрэп, который перевыбирает дикторов, а не записи. Ни того, ни другого в `sciwhisper-eval` сейчас нет. Пока их нет, подсчёт test запрещён. Бутстрэп по записям вместо дикторов этот протокол не принимает.

Рядом, на том же прогоне:

- oracle@K: доля примеров, где верный AST есть среди K гипотез;
- WER по словам. Метрики WER в `sciwhisper-eval` сейчас нет. Пока её нет, подсчёт test запрещён;
- false scientific rewrite rate на прозаических записях voice-v1. Рост числителя относительно базы 1 — не выигрыш.

## Критерий

Успех, все условия сразу:

- нижняя граница парного 95%-интервала для разности (скор − база 1) по AST exact match строго выше нуля;
- числитель false scientific rewrite rate на прозе не больше, чем у базы 1.

Отдельного минимального эффекта сверх нуля план числом не задаёт. Этот протокол таким числом его не добавляет. Более жёсткий порог — новая версия файла до первого подсчёта test.

Отказ от гипотезы, любой из пунктов, и он публикуется как результат:

- интервал содержит ноль или целиком ниже нуля;
- числитель oracle@K равен числителю top-1: верного AST в списке нет сверх первой гипотезы;
- числитель ложных переписываний прозы вырос.

## Запечатано

Пусто. До первого подсчёта test сюда вписываются температура, восемь seed и сетка λ. Дата вписывается вручную, не из часов машины.

## Чего файл не разрешает

- Менять корпус, таксономию серьёзности, ворота или контракт AST, чтобы улучшить число.
- Считать `dev-seed-*` ответом на вопрос 1.
- Подбирать λ по `spk04` или `spk05`.
- Встраивать выбранный скор в продукт по итогам одного прогона.
- Называть уровень разбора `confidence` вероятностью.
