# Security Policy

## Supported versions

До первого стабильного релиза поддерживается только последняя опубликованная версия Technical Preview.

## Reporting a vulnerability

До создания публичного security contact не публикуйте потенциальную уязвимость вместе с чувствительным аудио или документами. Откройте минимальный issue без секретных данных и попросите сопровождающего предоставить приватный канал.

Особенно важны сообщения о:

- неожиданных сетевых запросах;
- сохранении временного аудио;
- выполнении команд из распознанного текста;
- небезопасной работе с путями к модели и аудиофайлам;
- потере или перезаписи clipboard после появления desktop shell.

SciWhisper не должен исполнять содержимое транскрипции как shell-команду.
