# Тестирование SciWhisper без знания программирования

Эта инструкция предназначена для студентов, преподавателей и других тестировщиков Technical Preview.

## 1. Что понадобится

- Windows 11 x64, актуальная macOS или Linux с графической средой;
- распакованный официальный release-архив SciWhisper;
- микрофон только для необязательного голосового теста;
- локальный Whisper backend и model pack для голосового теста.

Self-test формул работает без Whisper, микрофона и интернета.

## 2. Безопасный запуск

1. Скачайте архив только со страницы официального релиза проекта.
2. Сверьте checksum, если он опубликован рядом с архивом.
3. Распакуйте архив в отдельную папку.
4. На Windows запустите `SciWhisper-Test.cmd`; на macOS — `SciWhisper-Test.command`; на Linux — `SciWhisper-Test.sh`.
5. Если политика организации блокирует неизвестный файл, не обходите её: сообщите сопровождающему или системному администратору.

Скрипт сначала запускает локальный self-test из восьми примеров, затем показывает диагностику Whisper. После этого можно отказаться от микрофонного теста.

На Windows настройки открываются двойным кликом по `SciWhisper-Settings.cmd`. На macOS и Linux используйте `sciwhisper settings`.

Для проверки menu-bar режима на macOS запустите двойным кликом `SciWhisper.app`. Разрешите для него Microphone, Input Monitoring и Accessibility, затем перезапустите приложение. Accessibility требуется именно для автоматической вставки `Cmd+V`; без него распознанный результат безопасно остаётся в буфере. После запуска в верхней строке меню появляется `SW`.

Если научная конструкция пока не разобрана, SciWhisper вставляет обычный текст Whisper. Чтобы посмотреть точное распознавание, откройте `SW` → `Скопировать raw Whisper` и вставьте содержимое буфера в отчёт об ошибке.

## 3. Ожидаемый self-test

В конце должна появиться строка:

```text
Готово: 8/8 проверок пройдено.
```

Self-test проверяет:

- химическую формулу;
- химическую реакцию;
- квадратное уравнение;
- интеграл;
- длинное выражение с дзетой, неявным умножением, экспонентой и делением;
- физическую величину с единицей.

## 4. Голосовой тест

Если `doctor` показывает найденный backend и локальную модель, согласитесь на необязательный тест микрофона и произнесите после начала записи:

```text
гидроксид меди два превращается в оксид меди два плюс вода
```

Ожидаемый Unicode:

```text
Cu(OH)₂ → CuO + H₂O
```

Ожидаемый LaTeX:

```text
\ce{Cu(OH)2 -> CuO + H2O}
```

Если модель отсутствует, программа должна сообщить об этом и не должна начинать скачивание.

## 5. Дополнительные фразы

| Домен | Произнесите | Ожидается |
|---|---|---|
| Химия | ион меди два плюс | Cu²⁺ |
| Химия | медный купорос | CuSO₄·5H₂O |
| Математика | икс в квадрате плюс два икс минус три равно нулю | x² + 2x − 3 = 0 |
| Математика | сета умноженное на три икс плюс экспонента от икс делённое на икс в квадрате | ζ·3x + exp(x)/x² |
| Математика | интеграл от эф дэ икс | ∫ f dx |
| Физика | лямбда равно шестьсот тридцать два нанометра | λ = 632 нм |

## 6. Как сообщить об ошибке

Скопируйте и заполните:

```text
ОС и версия:
Модель компьютера / процессор:
Версия SciWhisper:
Команда или launcher:
Домен:
Что я произнёс:
Что показал Whisper:
Что вставил/вывел SciWhisper:
Что ожидалось:
Повторяется ли ошибка:
Использовался ли фоновый шум:
```

Не прикладывайте личные разговоры, документы или аудио с другими людьми. Для воспроизведения лучше заново записать только проблемную научную фразу.

## 7. Что пока не считается ошибкой

- отсутствие нативного окна настроек на macOS/Linux — там используется терминальная помощница;
- отказ глобальной клавиши до выдачи Input Monitoring/Accessibility на macOS;
- отказ Word-вставки вне Windows или без установленного Microsoft Word;
- отображение LaTeX как кода в исходнике `.tex`;
- линейная дробь в обычном текстовом поле;
- первая транскрипция дольше целевого времени из-за загрузки внешнего Whisper CLI.

Актуальный список находится в [KNOWN_LIMITATIONS.md](KNOWN_LIMITATIONS.md).
