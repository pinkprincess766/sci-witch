# Приватность SciWhisper Technical Preview

SciWhisper предназначен для полностью локальной обработки.

## Что происходит с данными

- Микрофон записывается только после явного запуска команды `rec`.
- Запись и сконвертированные WAV-файлы размещаются во временной директории.
- Временная директория удаляется автоматически после завершения обработки, включая большинство ошибочных завершений внутри процесса.
- Транскрипция и научный AST не отправляются по сети.
- История в текущем CLI не ведётся.
- Телеметрии, аналитики и crash upload нет.

## Модели

SciWhisper использует только уже имеющуюся локальную модель. Перед запуском `openai-whisper` наличие модели проверяется; отсутствующая модель приводит к ошибке, а не к автоматическому скачиванию.

Модель устанавливается пользователем или поставляется отдельным офлайн-пакетом. Проверка и скачивание модели не входят в runtime SciWhisper.

## Ограничения preview

- Внешний Whisper-процесс получает путь к локальному временному аудиофайлу.
- Аварийное завершение всего процесса или операционной системы может оставить временный файл. Это следует проверять отдельно на каждой целевой платформе.
- Команда `transcribe` читает выбранный пользователем исходный файл и не удаляет его; удаляется только временная сконвертированная копия.
- Debug-режимов с сохранением аудио сейчас нет.

Перед публичным Windows-релизом проводится отдельная проверка файловой системы и сетевого трафика.
