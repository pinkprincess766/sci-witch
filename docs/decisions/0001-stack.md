# ADR-0001: язык, поставка и границы Этапа 1

**Статус:** принято; границы Этапа 1 исторические
**Дата:** 2026-08-30

## Решение

- Язык ядра и CLI: **Rust** (portable, без Python runtime в поставке).
- Словари и course packs: **YAML** с `schema_version: 1`; неизвестная большая версия — ошибка загрузки.
- Первый пользовательский интерфейс: **CLI** `sciwhisper format`.
- В исходном Этапе 1 ASR был отложен, чтобы не блокировать parser/renderer golden-тесты. Сейчас интерфейс и CLI-адаптер ASR уже добавлены.
- Word: Этап 1 генерирует **OMML**. COM-вставка — Этап 3, только Windows.
- Tray / PTT / WASAPI — Этап 2, `#[cfg(windows)]`.

## Почему не Python + faster-whisper

ТЗ требует автономную Windows-поставку без Python и без сетевого bootstrap. `whisper.cpp` + Rust это удовлетворяет. `faster-whisper` допустим только как исследовательский стенд.

## Последствия

- Parser и словари тестируются на macOS/Linux/Windows одинаково.
- Latency P50/P95 и native Word не являются критериями Этапа 1.
- Смена ASR не должна менять AST.

## Текущее состояние

- Этап 1 завершён: core, CLI, словари и renderers реализованы.
- Этап 2 начат: есть микрофонный CLI и запуск локального Whisper, но нет tray, PTT и постоянного runtime модели.
- Этап 3 не начат: OMML генерируется, COM-вставки в Word нет.
