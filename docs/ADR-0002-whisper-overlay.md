# ADR-0002: SciWhisper — надстройка на Whisper

**Статус:** принято
**Дата:** 2026-08-30

## Решение

SciWhisper **не заменяет** Whisper. Конвейер:

```
аудио → локальный Whisper ASR → нормализация → parser/AST → renderer
```

Whisper даёт `Transcript` (текст, язык, сегменты, no_speech). Научный смысл восстанавливает `sciwhisper-core`. Веса Whisper не дообучаются: bias идёт через `initial_prompt`.

Интерфейс `AsrEngine` заменяемый:

1. **Development adapter:** установленная команда `whisper` из `openai-whisper` с заранее кэшированной локальной моделью.
2. **Windows portable по ТЗ:** `whisper.cpp` (`whisper-cli`) через тот же trait, без Python.

Во время транскрипции сеть не используется. Модель берётся из локального кэша.

## Почему whisper.cpp ещё не встроен

Первый spike использовал уже установленный `openai-whisper`, чтобы проверить весь путь от аудио до AST. Публичная Windows-поставка должна перейти на встроенный или сопровождаемый `whisper.cpp`, не требующий Python. Смена backend не должна менять AST.

Текущий CLI запускает внешний процесс на каждую транскрипцию и поэтому не выполняет целевое требование удержания модели в RAM. Это осознанное ограничение technical preview.
