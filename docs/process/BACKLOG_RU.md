# Список задач (на 04.10.2026)

Задачи для работы с агентами, в первую очередь с Grok. Каждая — законченный
кусок с проверяемым результатом. Общие правила — [`AGENTS.md`](../../AGENTS.md);
порядок работы в паре — [`PAIR_WORKFLOW_RU.md`](PAIR_WORKFLOW_RU.md).

Обе крупные работы 04.10.2026 — правило запятых и перечислений и удаление
продуктовой части — уже в `experimental`; можно начинать.

## Что требовать от исполнителя в каждой задаче

Это то, на чём за последние недели спотыкались все исполнители, и Grok в том
числе. Стоит прямо вставлять в каждую постановку.

- **Тест с обеих сторон.** Одна сторона — дефект больше не проходит, другая —
  законное поведение не сломалось. И доказательство, что тест дефекта **падает
  без правки** (временно откатить правку, прогнать, вернуть).
- **Таблица «до/после»** на десятках фраз для любой правки разбора: бинарь «до»
  собрать до первой правки. Любая фраза, которая была словами и стала формулой, —
  рост опасных переписываний; так нельзя, даже если что-то другое улучшилось.
- **Все пять проверок до конца** и число бинарей по строкам `test result:`.
  Плюс ворота и сравнение четырёх отчётов бенчмарка с опубликованными.
- **Номера строк.** `docs/grammar/*.ebnf` и `ANALYSIS_RU.md` ссылаются на строки
  кода с допуском 40 (`crates/sciwhisper-core/tests/grammar_first_follow.rs`).
  Сдвинул код — пересчитай ссылки **по коду** (строка начала функции), а не
  прибавлением смещения. Не прятать сдвиг через `#[rustfmt::skip]`.
- **Числа в статье** — только макросами из `paper/numbers.tex`; после
  намеренного изменения отчёта —
  `PAPER_NUMBERS_WRITE=1 cargo test -p sciwhisper-eval --test paper_numbers`.
- **Отчёт по схеме — один раз, в конце.** В первом раунде этапа 3А часть 2 Grok
  прислал отчёт «читаю план» первым же сообщением и остановился; помогло прямое
  указание «отчёт — только в конце».
- **Не трогать** `git config` (worktree делит его с основным репозиторием),
  опубликованные корпуса `research/data/*` с SHA-256 в манифестах.

## A. Грамматика (этап 3А плана)

### A1. Число разборов на фразу — мера неоднозначности

- **Цель.** Плановый пункт «отчёт о неоднозначности: сколько фраз имеет больше
  одного разбора». Число разборов — ещё и будущий признак для калибровки (этап 3В).
- **Где.** `crates/sciwhisper-grammar/src/earley.rs` (`recognise`, `Recognition`,
  `MAX_TOKENS`, `MAX_ITEMS`), `tests/differential.rs`,
  `research/results/grammar-differential-v1.json`.
- **Что сделать.** Посчитать число деревьев вывода для принятой цепочки — по
  таблице Earley без построения деревьев (динамика по завершённым состояниям) или
  через упакованный лес (SPPF). Явный предел `MAX_PARSES` (например 1000; больше —
  «≥ MAX»), `pub const` и тест границы. В дифференциальный отчёт добавить
  распределение «1 / 2 / 3–10 / > 10 разборов» по корпусам и список фраз с
  наибольшим числом. Новая версия отчёта — `grammar-differential-v2.json`, v1 не
  трогать.
- **Готово, когда.** Юнит-тесты на классике: `E → E + E | a` для `a+a+a`
  даёт 2 разбора, для `a+a+a+a` — 5 (числа Каталана); однозначная грамматика — 1;
  ε-цепочки не размножают разборы бесконечно (тест). Раздел в
  `docs/grammar/ANALYSIS_RU.md` с цифрами из отчёта.
- **Камни.** Пустые правила (ε) и циклы `A → A` дают бесконечно много разборов —
  счёт должен это ловить и отдавать «≥ MAX», а не зависать.
- **Размер.** Средний.

### A2. Химия в Earley-эталоне

- **Цель.** Сейчас эталон проверяет только математику; `docs/grammar/chem.ebnf`
  не сравнивается с кодом.
- **Где.** `crates/sciwhisper-core/src/research.rs` (`math_token_classes`),
  `crates/sciwhisper-core/src/parser/chemistry.rs`, `docs/grammar/chem.ebnf`.
- **Что сделать.** Аналог `math_token_classes` для химии — классы слов, которыми
  написан `chem.ebnf` (элемент, буква, число, связка, маркер иона…). Разборщик
  химии — упорядоченный выбор (как PEG), это записано в заголовке `chem.ebnf`;
  Earley проверит надмножество. Дифференциальный тест для химии на тех же четырёх
  корпусах.
- **Готово, когда.** Таблица клеток «оба / только Earley / только парсер» для
  химии; каждое «только парсер» объяснено или заведено как дефект (тестом).
- **Камни.** Химия читает названия по словарям (`elements.yaml`,
  `substances.yaml`), классы слов пересекаются («кислород» — и вещество, и
  элемент). Описать, как это решено, в отчёте.
- **Размер.** Большой.

### A3. PCFG — вероятности правил

- **Цель.** Плановый пункт: `log P(дерево)` и перплексия грамматики на dev.
- **Что сделать.** Оценить вероятности правил `math.ebnf` по частотам использования
  в разборах фраз train-части корпусов (если разбор неоднозначен — делить счёт
  поровну между разборами; это записать как упрощение). Перплексия на validation.
- **Готово, когда.** Отчёт `research/results/pcfg-v1.json`, тест «вероятности
  альтернатив каждого нетерминала в сумме дают 1», тест на игрушечной грамматике
  с известным ответом.
- **Камни.** Нужен A1 (разборы). Данных мало — честно написать, что оценка на
  ~100 фразах — демонстрация метода, а не модель языка.
- **Размер.** Большой.

### A4. Восстановление после ошибок распознавания (Ахо–Петерсон)

- **Цель.** Плановый пункт: найти ближайшую по редакционному расстоянию цепочку
  языка грамматики (error-correcting parsing, Aho & Peterson 1972; Lyon 1974).
- **Что сделать.** Earley с операциями вставки/удаления/замены токена и стоимостью;
  предел числа правок `MAX_EDITS` (явная константа). Сравнить с эвристиками
  `lattice.rs` (`VowelRepair`, `BridgeWordsDropped`, `SelfCorrection`) на фразах с
  ошибками из `ambiguous-v2` (тег `asr-error`).
- **Размер.** Большой. Исследовательский, результат — отчёт, а не изменение
  продукта.
