# Приватность sci-witch

SciWhisper предназначен для полностью локальной обработки.

## Что происходит с данными

- Микрофон записывается только после двойного нажатия Control либо явного запуска команды `rec`.
- Запись и сконвертированные WAV-файлы размещаются во временной директории.
- Временная директория удаляется автоматически: она принадлежит объекту-владельцу, и её удаление происходит при выходе из области видимости, а не отдельным вызовом, который мог бы быть пропущен на ветке ошибки. Это проверяется тестами для успеха, неудачного запуска движка, ненулевого кода возврата, тайм-аута, нечитаемого результата и отсутствующей модели.
- Отменённая клавишей Esc запись не пишет файл вообще: до завершения записи звук существует только в памяти.
- Распознанный текст и научные формулы не отправляются по сети.
- История в текущем CLI не ведётся.
- Телеметрии, аналитики и автоматической отправки отчётов об ошибках нет.

## Модели

SciWhisper использует только уже имеющуюся локальную модель и **никогда** не обращается к сети — ни при запуске, ни при отсутствии модели, ни при её повреждении.

В комплекте для Windows модель поставляется отдельным офлайн-пакетом (model pack) вместе с файлом `MODEL_MANIFEST.json`, где записаны имя, размер, SHA-256, источник и лицензия. Перед запуском движка проверяется размер файла; команда `sciwhisper doctor --verify-model` дополнительно считает полную контрольную сумму. Отсутствующая, неполная или повреждённая модель приводит к понятному сообщению на русском языке, а не к скачиванию и не к переключению на Python.

Это **контроль целостности, а не доказательство подлинности**: хеш лежит в том же архиве, что и модель, поэтому он ловит обрыв загрузки и повреждение файла, но не может подтвердить происхождение байтов. За происхождение отвечают закрепление версии и контрольной суммы в репозитории проекта и release workflow, который их применяет и отказывается публиковать при несовпадении. Официальный комплект дополнительно отказывается работать с model pack, в манифесте которого написано, что эта сверка не выполнялась. Криптографической подписи артефактов в этой версии нет.

Отсутствие сетевых обращений в слое распознавания проверяется тестом, который ищет в исходниках HTTP-клиенты и сетевые вызовы, — то есть по всем ветвям кода, а не только по тем, что покрыты сценариями.

## Ограничения предварительной версии

- Внешний Whisper-процесс получает путь к локальному временному аудиофайлу.
- Аварийное завершение всего процесса или операционной системы может оставить временный файл. Это следует проверять отдельно на каждой целевой платформе.
- Команда `transcribe` читает выбранный пользователем исходный файл и не удаляет его; удаляется только временная сконвертированная копия.
- Debug-режимов с сохранением аудио сейчас нет.

Перед публичным Windows-релизом проводится отдельная проверка файловой системы и сетевого трафика.

## Запись исправлений

По умолчанию **выключена**. Если включить её в меню значка или командой
`sciwhisper settings set remember_corrections true`, программа будет
дописывать в файл `corrections.jsonl` рядом с настройками те случаи, когда
вы выбрали не тот вариант, который был вставлен: услышанный текст,
вставленный результат и ваш выбор.

Файл остаётся на вашем компьютере. Он никуда не отправляется, ничто в
работе программы от него не зависит, и его можно удалить в любой момент.
Посмотреть накопленное: `sciwhisper corrections`.

Файл перестаёт пополняться после 10 000 записей или 16 МиБ — вместо того
чтобы затирать самые ранние или незаметно занимать всё больше места.
