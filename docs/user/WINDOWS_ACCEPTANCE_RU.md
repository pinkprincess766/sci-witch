# Приёмка sci-witch на Windows 11

Это единственная часть версии `0.2`, которую нельзя выполнить автоматически: нужна живая
Windows, живой микрофон и настоящий Microsoft Word. Всё остальное закрыто тестами и CI.

Заполните форму целиком и приложите её к issue. **Пустая графа «Что получилось» — это
непройденный пункт, а не мелочь.** Если что-то не работает, это и есть результат приёмки.

## 15. Итог

```
Пунктов пройдено:            ____ из ____
Заблокировано:               ____________________________________
Готово к внешним тестерам:   да / нет
```

Разделы 1–9 относятся к версии `0.2`, разделы 10–14 — к `0.4`. Заполнять можно порознь,
но засчитывать — только по факту выполнения.

Если хотя бы один пункт раздела 6 не выполнен ни на одной версии Word, версия `0.2`
не считается принятой: нативная вставка уравнения — её главное обещание.

Для `0.4` таких обязательных пунктов два, и оба про необратимость:

* **11.7 и 11.8** — обновление обязано пройти и обязано оставить рабочий резерв. Замена,
  после которой нельзя вернуться, хуже отсутствия обновления.
* **10.6** — удаление не должно уносить настройки пользователя.
