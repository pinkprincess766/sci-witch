# Changelog

Все существенные изменения проекта фиксируются в этом файле.

## [Unreleased]

### Added

- Код проекта переведён на Apache License 2.0; добавлены `NOTICE`, его включение во все CI/release-бандлы и явные условия лицензирования вкладов. Собственные словари и корпуса остаются под CC BY 4.0.
- Новая рыжая ведьмочка на метле подмигивает в system tray; в macOS menu bar используется её чёрно-белая template-версия, автоматически подстраивающаяся под светлую и тёмную панель.
- Добавлены песочные иконки приложения для macOS (PNG) и Windows (ICO); Windows-окно настроек использует фирменную иконку.
- Лексикон получил проверяемые ссылки на IUPAC Blue Book/Red Book, статус retained names и отдельное поле для локальных ASR-алиасов.
- Добавлены наблюдённые ASR-алиасы `пермангнат калия`, `павликовая кислота` и `кавликовая кислота`; они не смешиваются с нормативными названиями.
- Добавлен подтверждённый IUPAC набор распространённых retained names: органические кислоты, ацетон, фенол, мочевина, глицерин, стирол и галоформы.
- Rust workspace с отдельными core, ASR и CLI crates.
- Детерминированный AST и parsers химии, математики и физики.
- Unicode, LaTeX/`mhchem` и OMML renderers.
- Локальные Whisper CLI adapters и запись микрофона.
- Golden-корпус более чем из 300 текстовых фраз.
- Команды `self-test` и `demo` для проверки без микрофона.
- Инструкции и launchers для тестировщиков без знания программирования.
- Tray, глобальный PTT, локальная вставка и тёплый процесс Whisper.
- Терминальная помощница `sciwhisper settings` для macOS/Linux.
- Небольшое Windows WinForms-приложение настроек с локальной диагностикой.
- Linux release bundle и строгие fmt/Clippy gates в CI.
- Полноценный macOS `SciWhisper.app` с иконкой, bundle identity и описаниями разрешений.
- Документирована архитектура гибридного научного декодера: грамматические кандидаты, валидаторы, контекстное смещение и локальный нейросетевой ранжировщик.

### Fixed

- Однозначные химические формулы внутри обычной диктовки теперь находятся непосредственно по лексикону, без отдельного неполного списка ключевых слов.
- Формулы, продиктованные последовательностью элементов и индексов, теперь компилируются и внутри обычного текста: `калий марганец о четыре` → `KMnO₄`.
- Пунктуация теперь разрывает формульную последовательность, поэтому математическое `эн, а в...` не превращается в ложную химическую цепочку `NNaV`.
- Математические выражения теперь компилируются внутри обычного абзаца рядом с химией: `пси в квадрате умножить на x в кубе равно 10 в четвертой степени` → `ψ²·x³ = 10⁴`.
- Добавлены формы произвольной порядковой степени и связки реакций `окисляется до` / `восстанавливается до`.
- Русское пояснение `а в числителе` защищено от ложного преобразования в латинские символы `a·v`.
- Математические операторы и русские числительные теперь загружаются из версионированных YAML-файлов; дублирующий жёстко заданный список фраз удалён из parser runtime.
- Смешанные научные фрагменты выбираются общим взвешенным алгоритмом непересекающихся интервалов вместо последовательного жадного переписывания Chemistry → Math → Physics.
- Введена цена открытия научного интервала, поэтому `KMnO₄` выигрывает как единый AST, а не как три раздельных кандидата `K`, `Mn`, `O₄`.
- Неоднозначное `дельта три` оставляется словами; явные команды `дельта нижний индекс три`, `дельта умножить на три` и `дельта в кубе` разбираются структурно.
- Добавлен семантический валидатор баланса атомов и зарядов: он предупреждает о некорректном уравнении, не изменяя продиктованный AST.
- Добавлен подтверждённый материал `феррит цинка` / ASR-форма `феррит Zn` → `ZnFe₂O₄` с источником PubChem.
- Учтены падежная ASR-форма `феррита Zn` и множественные связки реакций вроде `превращаются в`.
- Математический AST получил типизированные стандартные функции `sin/cos/tan/cot/ln/log/exp`, интегралы с произнесённым дифференциалом `дэ икс` и ASR-вариант `под икс`.
- LaTeX и Word/OMML теперь отображают естественное `делённое на` нативной вертикальной дробью; Unicode сохраняет переносимый линейный вид.
- Добавлены наблюдённые варианты греческой дзеты `зета` и `сета`; неявное умножение вроде `3x` сохраняется в стандартной математической записи.
- LaTeX-рендерер теперь покрывает весь греческий алфавит стандартными командами вместо сырого Unicode там, где доступна LaTeX-команда.
- Добавлена воспроизводимая Windows x64 MSVC-сборка со статическим CRT, пользовательским launcher `SciWhisper.cmd`, отдельным WinForms-окном настроек и проверкой PE-архитектуры/self-test в CI.
- Неоднозначные одиночные названия `спирт` и `сода` больше не подменяются одной произвольно выбранной формулой.
- Добавлена точечная нормализация наблюдавшихся русских ASR-вариантов `гидраксид` и `кидроксидж лезо`; оба компилируются в гидроксид железа.
- При отсутствии явной настройки предпочитается уже скачанная `large-v3-turbo`, а не более слабая `base`.
- Вставка и undo на macOS используют физические keycodes `V`/`Z`; русская раскладка больше не превращает `Cmd+V` в `Cmd+A`.
- На macOS приложение теперь явно запрашивает и проверяет Accessibility; без него честно сообщает, что результат оставлен в буфере для ручного `Cmd+V`.
- Неразобранный научным parser текст Whisper теперь вставляется как обычный raw-текст вместо ошибки `nothing to insert`.
- Пункт menu bar для raw Whisper теперь копирует транскрипт в буфер и показывает его в строке статуса.
- Результат виртуальной вставки клавиш теперь проверяется; при запрете Accessibility текст остаётся в буфере, а не выдаётся ложный успех.
- Падение macOS 26 при первом событии клавиатуры: `rdev` заменён на keycode-only CGEvent listener без вызовов Text Input Services из фонового потока.
- Падение macOS 26 внутри устаревшего системного моста уведомлений: в menu-bar режиме статус теперь отображается самой tray-иконкой.
- На macOS значок меню теперь создаётся после запуска AppKit; исправлено тихое завершение `sciwhisper app` сразу после старта.
- Временные WAV-файлы теперь удаляются при освобождении владельца.
- Запись с `--seconds` больше не блокируется ожиданием Enter после таймера.
- Отсутствующая модель `openai-whisper` отклоняется до запуска backend, исключая автоматическое скачивание из runtime.

### Known limitations

- Tray/PTT, Windows-настройки и COM-интеграция Word ещё не проверены на живом Windows 11.
- Windows WinForms launcher пока не подписан.
- Внешний одноразовый Whisper CLI перезагружает модель; tray использует тёплый процесс.
