# Release bundle layout

## Windows x64 — автономный комплект

Пользовательский архив самодостаточен: Python не нужен, интернет во время работы не нужен,
программа ничего не скачивает.

```text
sci-witch-Windows-x64-<версия>/
  sciwhisper.exe
  whisper/
    whisper-cli.exe          # собирается из исходников в CI, см. model-pack.json
    BUILD_MANIFEST.json      # tag, commit, флаги сборки и SHA-256 движка
    MODEL_MANIFEST.json      # из model pack: имя, размер, SHA-256, источник, лицензия
    ggml-*.bin               # из model pack: сама модель
  SciWhisper.cmd
  SciWhisper-Test.cmd
  SciWhisper-Settings.cmd
  SciWhisper-Settings.ps1
  SciWhisper-App.ps1
  SciWhisper.ico
  README-WINDOWS.txt
  README.md LICENSE NOTICE DATA_LICENSE.md CHANGELOG.md SECURITY.md CONTRIBUTING.md
  docs/user/ docs/development/ docs/images/
```

Обязательный состав задан один раз в [`windows/BUNDLE_CONTENTS.json`](windows/BUNDLE_CONTENTS.json).
Его проверяют оба конца: release workflow — на собранном архиве до публикации,
и тест `the_bundle_manifest_describes_a_layout_the_application_accepts` — на том,
что приложение такой раскладке действительно доверяет.

`README-WINDOWS.txt` служит ещё и признаком «это официальный комплект»: если он есть,
а `whisper/whisper-cli.exe` нет, программа сообщает об ошибке упаковки и **не** уходит
молча в Python.

## Два артефакта вместо одного

| Артефакт | Размер | Что внутри |
|---|---|---|
| `SciWhisper-<версия>-Windows-x64.zip` | единицы МиБ | программа, движок, документация |
| `SciWhisper-<версия>-Windows-model-pack.zip` | ~190 МиБ | `MODEL_MANIFEST.json` + файл модели |

Почему раздельно:

* **размер** — основной архив остаётся маленьким, его можно скачать и запустить `SciWhisper-Test.cmd`
  ещё до загрузки модели;
* **скорость** — модель обновляется реже программы, и повторно качать её при каждом выпуске не нужно;
* **лицензия** — веса Whisper распространяются под MIT, то есть перепаковывать их можно,
  но происхождение и контрольная сумма должны быть видны отдельно, а не растворяться в общем ZIP.

Пользователь распаковывает оба архива в одну папку. Model pack разворачивается в `whisper/`.

## Закрепление внешних компонентов

[`windows/model-pack.json`](windows/model-pack.json) (`schema_version: 2`) — единственное место,
где закреплены версия whisper.cpp и модель. Незакреплённых записей не бывает: workflow
отказывается собирать и публиковать всё, что не сходится.

* `whisper_cpp.tag` — тег. Плавающие `latest`/`main`/`master` запрещены и проверяются
  и в workflow, и тестом.
* `whisper_cpp.commit` — **обязателен**. Клон сверяется с ним до компиляции; несовпадение
  останавливает сборку. Тег можно передвинуть, commit — нет.
* `models[].sha256` и `models[].size_bytes` — **обязательны**. Скачанный файл сверяется
  с обоими; несовпадение останавливает публикацию. Обхода нет.
* `models[].source_url` указывает на **неизменяемую ревизию** Hugging Face, а не на ветку:
  `resolve/main` позволил бы файлу измениться под тем же закреплённым хешем.

Ни движок, ни модель не хранятся в этом репозитории.

## Что проверяет `MODEL_MANIFEST.json`, а что нет

Внутри model pack лежит `MODEL_MANIFEST.json` с именем, размером, SHA-256, источником
и лицензией. Он даёт **контроль целостности**: программа замечает обрезанный, недокачанный
или повреждённый файл и говорит об этом по-русски.

Он **не является доказательством подлинности**. Хеш едет в том же архиве, что и файл:
кто способен подменить модель, способен подменить и манифест. Происхождение обеспечивают
две другие вещи — закрепление в этом репозитории и release workflow, который его применил.
Поле `verified_against_repository_pin` фиксирует, что применение действительно состоялось,
и официальный комплект (тот, рядом с которым лежит `README-WINDOWS.txt`) **отказывается
работать** с пакетом, где стоит `false`. На машине разработчика самодельный пакет
по-прежнему допустим — там нет обещания официальности, которое можно было бы нарушить.

Настоящая подпись артефактов — отдельная задача и в этой версии не сделана.

## macOS arm64

```text
SciWhisper-macOS-arm64/
  SciWhisper.app/
  README.md LICENSE NOTICE DATA_LICENSE.md
  docs/user/
```

macOS-сборка автономного движка пока не получила: там по-прежнему используется
локально установленный whisper.cpp или Python Whisper.

Программа не скачивает ни модель, ни движок — ни при запуске, ни позже.
