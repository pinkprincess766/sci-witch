# Release bundle layout

Для пользовательского архива launcher и бинарник должны находиться рядом:

```text
SciWhisper-windows-x64/
  sciwhisper.exe
  SciWhisper-Test.cmd
  SciWhisper-Settings.cmd
  SciWhisper-Settings.ps1
  README.md
  LICENSE
  NOTICE
  DATA_LICENSE.md
  docs/user/
```

```text
SciWhisper-macOS-arm64/
  SciWhisper.app/
  README.md
  LICENSE
  NOTICE
  DATA_LICENSE.md
  docs/user/
```

Модель распознавания распространяется отдельно до окончательного решения о размере и лицензировании комплекта. Программа ничего не скачивает без явного действия пользователя.
