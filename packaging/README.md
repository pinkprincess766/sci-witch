# Release bundle layout

Для пользовательского архива launcher и бинарник должны находиться рядом:

```text
SciWhisper-windows-x64/
  sciwhisper.exe
  SciWhisper-Test.cmd
  SciWhisper-Settings.cmd
  SciWhisper-Settings.ps1
  README.md
  LICENSE
  NOTICE
  DATA_LICENSE.md
  docs/
```

```text
SciWhisper-macos/
  sciwhisper
  SciWhisper-Test.command
  README.md
  LICENSE
  NOTICE
  DATA_LICENSE.md
  docs/
```

```text
SciWhisper-linux-x64/
  sciwhisper
  SciWhisper-Test.sh
  README.md
  LICENSE
  NOTICE
  DATA_LICENSE.md
  docs/
```

Model pack распространяется отдельно до появления окончательного решения о размере и лицензировании bundle. Launcher не скачивает модель.
