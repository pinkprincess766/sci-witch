# Установщик Windows

Собирается из [`SciWhisper.iss`](SciWhisper.iss) при помощи Inno Setup 6 —
из того же каталога, что и переносимый ZIP, поэтому содержимое у них одно и то же.

```
ISCC.exe /DAppVersion=0.1.1-rc1 /DSourceDir=bundle\sci-witch-Windows-x64-0.1.1-rc1 packaging\windows\SciWhisper.iss
```

## Решения, которые не косметические

**Установка per-user**, в `%LOCALAPPDATA%\Programs\SciWhisper`.

Установка в `Program Files` потребовала бы прав администратора — и не один раз при
установке, а **при каждом обновлении**: помощник заменяет каталог, а каталог в
`Program Files` защищён. Программа, которая регулярно просит администраторские права,
это программа, чьё окно UAC перестают читать. Per-user снимает вопрос: и установка, и
замена идут без повышения прав.

Цена: установка только для текущего пользователя. Для одного тестера это ровно то, что
нужно; общесистемная установка возможна через `PrivilegesRequiredOverridesAllowed=dialog`,
но тогда обновление начнёт спрашивать UAC.

**Ничего не запускается само.** Автозапуск при входе предлагается **снятой** галочкой,
периодической проверки обновлений нет вообще. Пользователь, которому нужна диктовка при
входе, поставит галочку; пользователь, которому не нужна, не должен замечать и снимать её.

**Удаление не трогает настройки.** `[UninstallDelete]` убирает только то, что создали
установщик и обновлятор. Ничего из `%APPDATA%` не удаляется: настройки и правки словаря
принадлежат пользователю, и деинсталлятор, который их стирает, решил за него то, что
решать было не ему.

## Чего установщик не делает

* **Не подписан.** SmartScreen покажет предупреждение, и предупреждение верное: за эти
  байты никто не поручился. Подпись Developer ID / code signing — отдельная задача 0.5.
* **Не кладёт модель.** Модель едет отдельным model pack и распаковывается в
  `whisper/`. Комплект без модели пригоден для самопроверки — это осознанно.
* **Не проверялся на живой Windows.** Скрипт собирается в CI, но установка, ярлыки,
  автозапуск и удаление на настоящей Windows 11 не выполнялись ни разу. До заполнения
  [WINDOWS_ACCEPTANCE_RU.md](../../docs/user/WINDOWS_ACCEPTANCE_RU.md) считать его
  непроверенным.
