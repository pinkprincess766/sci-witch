SCIWHISPER ДЛЯ WINDOWS 11 x64

1. Распакуйте весь ZIP в обычную папку. Не запускайте файлы прямо из архива.
2. Дважды нажмите SciWhisper.cmd. Ведьмочка появится в области уведомлений рядом с часами.
3. Удерживайте Ctrl+Shift+Space, говорите и отпустите клавиши.
4. Настройки открываются через SciWhisper-Settings.cmd.
5. Первичная безопасная проверка запускается через SciWhisper-Test.cmd.

Программа работает локально. Модель Whisper в этот небольшой RC-архив не включена.
Если диагностика сообщает, что backend или модель не найдены, установите локальный
Whisper по инструкции docs\TESTING_RU.md. Автоматического скачивания моделью нет.

Для нативной вставки формул в Microsoft Word выберите формат word в настройках.
Word должен быть уже открыт, а курсор — находиться в месте вставки.

Это Technical Preview: Windows-сборка скомпилирована и проверена автоматически,
но tray, микрофон и Word COM ещё требуют приёмки на реальном компьютере Windows 11.
