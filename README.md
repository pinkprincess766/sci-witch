# sci-witch

_Бесплатный локальный голосовой ввод химических формул, математики и физических обозначений в обычный текст, LaTeX и Microsoft Word._

**Статус: предварительная версия для тестирования. Двойное нажатие Control запускает и завершает запись, речь распознаётся локально, а результат вставляется в активное поле. Вставку редактируемых формул в Microsoft Word ещё нужно проверить на настоящем компьютере с Windows 11 и установленным Word.**

**sci-witch** — бесплатная программа для голосового ввода научных формул. Whisper распознаёт речь, а sci-witch превращает сказанное в химические формулы, математические выражения и физические обозначения. В названиях некоторых файлов встречается `SciWhisper` — это внутреннее техническое имя программы.

```text
микрофон / аудиофайл / готовый текст
  → локальное распознавание речи
  → понимание научной записи
  → обычный текст / LaTeX / редактируемая формула Word
```

Аудио и научный текст не отправляются в облако. Без установленной локальной модели голосовая запись недоступна, но преобразование уже готового текста продолжает работать.

## Что можно продиктовать

| Направление | Скажите | Результат |
|---|---|---|
| Химия | `перманганат калия` | `KMnO₄` |
| Химия | `гидроксид меди два превращается в оксид меди два плюс вода` | `Cu(OH)₂ → CuO + H₂O` |
| Математика | `икс в квадрате плюс два икс минус три равно нулю` | `x² + 2x − 3 = 0` |
| Математика | `интеграл от нуля до единицы икс в квадрате по икс` | `∫₀¹ x² dx` |
| Физика | `лямбда равно шестьсот тридцать два нанометра` | `λ = 632 нм` |

## Установка

Готовые сборки публикуются на странице [«Выпуски» в GitHub](https://github.com/pinkprincess766/sci-witch/releases). Для текущей предварительной версии подготовлены два архива:

| Система | Файл в релизе | Как запустить |
|---|---|---|
| Windows 11, Intel/AMD 64-bit | `SciWhisper-0.1.1-rc1-Windows-x64.zip` | распаковать ZIP и открыть `SciWhisper.cmd` |
| macOS 12+, Apple Silicon | `SciWhisper-0.1.1-rc1-macOS-arm64.zip` | распаковать ZIP и открыть `SciWhisper.app` |

Это переносимые сборки, а не классические установщики: в Windows пока нет привычного `Setup.exe`, а в macOS — образа DMG. Права администратора не нужны, но архив необходимо полностью распаковать.

### Быстрый старт на Windows

1. Скачайте `SciWhisper-0.1.1-rc1-Windows-x64.zip` и полностью распакуйте его в обычную папку.
2. Запустите `SciWhisper-Test.cmd`: он без микрофона проверит, что основные функции работают.
3. Запустите `SciWhisper.cmd`. Ведьмочка появится в области уведомлений рядом с часами.
4. Дважды нажмите Control, говорите, затем дважды нажмите Control ещё раз; `Esc` отменяет запись.
5. Настройки открываются через `SciWhisper-Settings.cmd`.
6. Чтобы получить в Microsoft Word обычную редактируемую формулу, выберите формат `word`, откройте Word и поставьте курсор в место вставки.

Дополнительные библиотеки Visual C++ устанавливать не требуется. Цифровой подписи пока нет, поэтому Windows SmartScreen может показать предупреждение о неизвестном издателе.

### Быстрый старт на macOS

1. Скачайте и распакуйте `SciWhisper-0.1.1-rc1-macOS-arm64.zip`.
2. Переместите `SciWhisper.app` в удобную папку и откройте его двойным нажатием.
3. Разрешите доступ к микрофону, мониторингу ввода и универсальному доступу в системных настройках macOS.
4. Дважды нажмите Control, говорите, затем дважды нажмите Control ещё раз.

### Важное ограничение голосовой версии

Модель распознавания речи не включена в небольшие архивы. Встроенная проверка и преобразование уже готового текста работают сразу, но для голосовой записи требуется установленный на компьютере `openai-whisper` либо `whisper.cpp` с заранее скачанной моделью. sci-witch ничего не скачивает автоматически и не отправляет аудио в облако.

Значок в области уведомлений Windows, запись с микрофона и вставка формул в Word проходят автоматические проверки, но до стабильного выпуска их ещё нужно проверить вручную на настоящем компьютере с Windows 11. Версия для macOS проверена как приложение, однако пока не заверена Apple.

## Что уже работает

- дословный набор химических формул и реакций;
- структурированная математика: порядок действий, умножение без явного знака, редактируемые дроби, степени, корни, суммы, интегралы и стандартные функции;
- физические символы, единицы и векторы;
- вывод в обычный текст, LaTeX/`mhchem` и редактируемые формулы Microsoft Word;
- локальный микрофон и обработка аудиофайла;
- выбор между установленными `openai-whisper` и `whisper.cpp` для распознавания речи;
- более 300 проверочных фраз по химии, математике и физике;
- встроенная проверка без микрофона и подключения к интернету.

## Математика под капотом

sci-witch устроена не как «Whisper плюс таблица замен», а как небольшой научный компилятор. Whisper определяет, **какой текст был произнесён**, после чего детерминированное ядро строит и проверяет его научную структуру.

```text
аудио a → log-Mel спектрограмма → Whisper → текст x
        → допустимые научные разборы C(x) → типизированный AST y
        → проверки химии/синтаксиса → Unicode / LaTeX / Word
```

Под капотом работают несколько независимых математических механизмов:

- **формальные грамматики и AST** сохраняют порядок действий, границы дробей, индексы, заряды и стороны реакции;
- **динамическое программирование** выбирает лучший набор непересекающихся научных фрагментов внутри обычной речи;
- **линейная алгебра** проверяет и предлагает коэффициенты химической реакции из уравнения

$$
\boxed{A\nu=0},
$$

- **точная рациональная арифметика** решает систему без ошибок округления и безопасно отказывается от подсказки при неоднозначности или переполнении;
- **независимые renderer-ы** превращают один и тот же AST в Unicode, LaTeX или редактируемое уравнение Word.

Например, для `H₂ + O₂ → H₂O` ядро находит минимальный положительный вектор коэффициентов $\nu=(2,1,2)^T$ и предлагает `2H₂ + O₂ → 2H₂O`. Продиктованная реакция при этом не изменяется незаметно: результат показывается отдельным предупреждением.

Подробный разбор формул, алгоритмов, сложности, ограничений и ссылок на реализацию: **[«Математика под капотом sci-witch»](docs/development/MATHEMATICS_RU.md)**. Более широкая схема проекта находится в [описании архитектуры](docs/development/ARCHITECTURE_RU.md), а будущий ML оценивается по отдельному [протоколу исследования](docs/development/ML_RESEARCH_RU.md).

## Химическая диктовка

sci-witch понимает как названия веществ, так и формулы, продиктованные по частям. Можно вводить индексы, заряды, распространённые названия и целые реакции.

| Произнесите | Результат |
|---|---|
| `гидроксид меди два` | `Cu(OH)₂` |
| `перманганат калия` | `KMnO₄` |
| `калий марганец о четыре` | `KMnO₄` |
| `ион меди два плюс` | `Cu²⁺` |
| `медный купорос` | `CuSO₄·5H₂O` |
| `серная кислота` | `H₂SO₄` |
| `гидроксид меди два превращается в оксид меди два плюс вода` | `Cu(OH)₂ → CuO + H₂O` |

Одна и та же химическая структура выводится в подходящем для выбранного места виде: обычными символами, как LaTeX/`mhchem` или как редактируемая формула Microsoft Word. Если фраза неоднозначна, программа сохраняет исходные слова, а не придумывает вещество.

## Математическая диктовка

sci-witch понимает строение математического выражения, поэтому степени, корни, дроби, суммы и интегралы не остаются одной плоской строкой. Результат можно вставить как обычный текст, LaTeX или редактируемую формулу Microsoft Word.

| Произнесите | Результат в обычном тексте |
|---|---|
| `икс в квадрате плюс два икс минус три равно нулю` | `x² + 2x − 3 = 0` |
| `пси в квадрате умножить на икс в кубе равно 10 в четвертой степени` | `ψ²·x³ = 10⁴` |
| `начало корня икс плюс один конец корня` | `√(x + 1)` |
| `интеграл от нуля до единицы икс в квадрате по икс` | `∫₀¹ x² dx` |
| `сета умноженное на 3x равно 10 в третьей степени плюс экспонента от икс деленное на x в квадрате` | `ζ·3x = 10³ + exp(x)/x²` |

Проверить математику без микрофона можно одной командой:

```bash
sciwhisper format --domain mathematics --renderer all \
  "интеграл от нуля до единицы икс в квадрате по икс"
```

Для этого примера обычный текст выглядит как `∫₀¹ x² dx`, а LaTeX — как `\int_{0}^{1} x^{2}\,dx`. Microsoft Word получает редактируемое уравнение. Фраза `делённое на` превращается в вертикальную дробь в LaTeX и Word, а в обычном текстовом поле сохраняется понятная запись через косую черту.

## Запись голосом

1. Дважды нажмите **Control** — начнётся запись.
2. Говорите. Возле указателя появится тонкий синий индикатор, а в системной панели — отметка записи.
3. Снова дважды нажмите **Control** — запись завершится, результат будет обработан и вставлен.

`Esc` отменяет запись. Обычные сочетания вроде `Control+C` и `Control+V` не запускают диктовку.

![Анимация состояния записи sci-witch](docs/images/si-witch-recording.gif)

Режим с удержанием клавиш тоже сохранён. По умолчанию это **Ctrl+Shift+Space**; **Ctrl+Shift+L** сразу выбирает LaTeX, а **Ctrl+Shift+W** — редактируемую формулу Microsoft Word.

На macOS разрешите программе доступ к микрофону, мониторингу ввода и универсальному доступу.

Windows-версия автоматически собирается и проверяется после изменений в проекте. Вставка редактируемой формулы должна работать, когда открыт Microsoft Word и курсор установлен в документе, но это ещё не проверено вручную на Windows 11.

## Настройки

На macOS и Linux запустите терминальную помощницу:

```bash
sciwhisper settings
# или явно
sciwhisper settings configure
```

Она последовательно предложит предметную область, формат вставки, язык, локальную модель и сочетания клавиш. Там же можно включить или отключить запуск двойным Control. Enter сохраняет текущее значение, а перед записью показывается подтверждение.

Дополнительные команды для опытных пользователей:

```bash
sciwhisper settings show
sciwhisper settings set domain chemistry
sciwhisper settings set output latex
sciwhisper settings set ptt Ctrl+Alt+Space
sciwhisper settings set double_control true
sciwhisper settings path
sciwhisper settings reset --yes
```

На Windows откройте двойным нажатием `SciWhisper-Settings.cmd`. Это небольшое локальное окно меняет те же настройки; приложение не использует интернет.

![Макет Windows-настроек sci-witch](docs/images/si-witch-windows-settings-mockup.png)

_Макет соответствует доступным настройкам; внешний вид стандартных элементов окна зависит от версии Windows и выбранного масштаба._

## Чего пока нет

- записей десяти живых носителей языка — сейчас есть только несколько синтезированных голосовых примеров;
- измерений скорости на выбранном для сравнения компьютере;
- полного сохранения содержимого буфера обмена, если в нём находятся файлы или изображения;
- подписанного установщика и полностью готового комплекта `whisper.cpp`, не требующего Python.

Полный список: [известные ограничения](docs/user/KNOWN_LIMITATIONS_RU.md).

## Проверка без микрофона

В скачанном архиве запустите `SciWhisper-Test.cmd` на Windows, `SciWhisper-Test.command` на macOS или `SciWhisper-Test.sh` на Linux. Скрипт безопасно проверит основные функции без микрофона и покажет результат.

Из терминала:

```bash
sciwhisper self-test
sciwhisper demo
sciwhisper doctor
```

Пошаговая инструкция без знания программирования: [docs/user/TESTING_RU.md](docs/user/TESTING_RU.md).

## Команды для опытных пользователей

```bash
# Уже распознанный текст — Whisper не нужен
sciwhisper format --domain chemistry "гидроксид меди два"

# Аудиофайл → локальный Whisper → формула
sciwhisper transcribe recording.wav --domain chemistry --renderer all

# Микрофон, автоматическая остановка через 6 секунд
sciwhisper rec --seconds 6 --domain chemistry --renderer all
```

Пример:

```text
сказано:  гидроксид меди два превращается в оксид меди два плюс вода
Unicode:  Cu(OH)₂ → CuO + H₂O
LaTeX:    \ce{Cu(OH)2 -> CuO + H2O}
```

Параметры команд:

- `--domain` выбирает предметную область: автоматическое определение, химия, математика, физика или обычный текст;
- `--renderer` выбирает формат результата: обычный текст, LaTeX, Microsoft Word или все форматы сразу;
- `--language ru` задаёт русский язык распознавания;
- `--model` задаёт название или локальный путь к модели;
- `--whisper <path>` указывает путь к программе распознавания речи.

## Локальный Whisper

Модели распознавания речи не входят в репозиторий. Перед голосовым тестом пользователь самостоятельно скачивает модель и указывает путь к ней либо помещает её в папку, где Whisper обычно хранит модели.

Для разработки сейчас поддерживаются:

- команда `whisper` из `openai-whisper` с уже кэшированной `.pt` моделью;
- `whisper-cli` из `whisper.cpp` с локальной GGML/GGUF-моделью.

Проверьте конфигурацию:

```bash
sciwhisper doctor
```

В окончательную сборку для Windows планируется включить `whisper.cpp` и локальную модель. Python не должен требоваться обычному пользователю.

## Сборка разработчиком

Требуется актуальная стабильная версия инструментов Rust.

```bash
cargo build --release
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo run -p sciwhisper-cli -- self-test
```

Архитектура:

```text
crates/sciwhisper-asr    распознавание речи, постоянно загруженная модель и микрофон
crates/sciwhisper-core   внутреннее представление формул, словари, разбор и вывод
crates/sciwhisper-shell  значок в системной панели, запись по горячей клавише, буфер обмена, Word
crates/sciwhisper-cli    format / rec / transcribe / app / settings / corpus / doctor
```
