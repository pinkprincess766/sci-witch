# Как участвовать в SciWhisper

Спасибо за помощь. SciWhisper особенно нуждается в воспроизводимых примерах русской научной речи, а не в больших недетерминированных переписываниях.

## Перед изменением кода

1. Прочитайте `SciWhisper_TZ.md` и соответствующий ADR.
2. Не смешивайте ASR, parser и renderer в одном изменении без необходимости.
3. Для нового выражения сначала добавьте минимальный failing test.
4. Не добавляйте облачную зависимость или автоматическое скачивание в runtime.

## Проверки

```bash
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo run -p sciwhisper-cli -- self-test
```

## Научные данные

- Полностью продиктованное выражение форматируется дословно.
- Shortcut-реакция требует точного совпадения и проверенного источника.
- Не добавляйте «общеизвестную» реакцию без условий и provenance.
- Укажите лицензию внешнего набора данных.

## Отчёты об ASR

Укажите raw Whisper transcript, ожидаемую нормализацию и результат renderer. Не публикуйте чужое аудио или чувствительные данные.

## Стиль изменений

- небольшие независимые patches;
- отсутствие `unwrap` в путях, зависящих от пользовательского ввода;
- временные файлы должны иметь RAII-владельца;
- ошибки не должны уничтожать raw transcript;
- новый renderer использует существующий AST и не парсит строку повторно.

## Лицензия вклада

Отправляя изменение для включения в SciWhisper, вы соглашаетесь лицензировать его на условиях Apache License 2.0 без дополнительных условий, если явно не указано иное. Данные и словари должны иметь лицензию, совместимую с [CC BY 4.0](DATA_LICENSE.md), и сопровождаться указанием источника.
